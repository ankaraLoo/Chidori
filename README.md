# Chidori
⚡ Chidori, arkadaşlarınızla eş zamanlı video izleyip sohbet etmenizi sağlayan yerel sunucu ve Android uygulamasıdır. Oynat, durdur ve sar işlemleri odadaki herkesle aynı anda gerçekleşir. YouTube ve doğrudan linkleri destekler; sayfalardan video yakalar, reklamları eler. Kolayca kurulur, tünel adresini otomatik ayarlar.
